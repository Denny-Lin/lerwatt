# Naming

**Lerwatt**, pronounced **LER-watt**: learning + watt. It shares the *ler-* prefix with [Lertick](https://github.com/Denny-Lin/lertick) (learning + tick), so the scheduler and the power manager read as one family. Repository: `Denny-Lin/lerwatt`. Planned daemon name: `lerwattd`.
